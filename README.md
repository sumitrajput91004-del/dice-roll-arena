# Dice Roll Arena 🎲

## About
Dice Roll Arena is an interactive dice rolling website built using HTML, CSS and JavaScript. It allows users to roll one or two dice and view their results.

## Features
- Roll one six-sided die.
- Roll two dice and calculate their total.
- Animated dice rolling.
- Recent roll history.
- Sound effects with a sound on/off toggle.
- Responsive design for desktop and mobile screens.

## Technologies Used
- HTML — webpage structure
- CSS — styling, layout and animations
- JavaScript — dice logic, event handling and sound effects
- Web Audio API — generates the sound effect

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open the file directly in a browser.

## Random Number Generation
JavaScript uses `Math.floor(Math.random() * 6) + 1` to generate an integer between 1 and 6.
